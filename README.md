# Tabela Interativa dos Limites de Velocidade para Carta de Condução

Uma aplicação interativa para aprender os limites de velocidade do código de estrada português.

## Como usar

- **Preencher a tabela**: Clique em qualquer célula com um sinal de interrogação (?) para inserir o limite de velocidade
- **Resposta correta**: A célula fica verde com o valor inserido
- **Resposta incorreta**: A célula mostra um 'x' e você pode tentar novamente
- **Veículo não autorizado**: Insira `0` se o veículo não pode transitar nessa via

## Características

✨ **Design moderno**: Interface limpa e responsiva para desktop e mobile

📱 **Otimizado para mobile**: Navegação horizontal com cabeçalho e coluna de veículos fixos para melhor experiência

🎯 **Feedback visual**: Indicadores de respostas corretas e incorretas com animações

📊 **Progresso**: Acompanhe quantas questões respondeu corretamente

🔄 **Recomeçar**: Botão para reiniciar a tabela a qualquer momento
